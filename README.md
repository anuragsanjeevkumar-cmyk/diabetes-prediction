# Diabetes Prediction using Machine Learning

## Overview

This project predicts diabetes progression using Machine Learning techniques. The dataset is loaded directly from Scikit-Learn and various data analysis and model training steps are performed to build a predictive model.

## Dataset

The dataset is loaded using:

```python
from sklearn.datasets import load_diabetes
```

The dataset contains medical measurements of patients and a target value representing disease progression.
